# AyniNexo

- Ejecuta `npm run lint`, `npm test` y `npm run build` antes de entregar cambios.
- Escribe la interfaz en español, con la excepción del tagline de marca.
- Mantén las reglas de elegibilidad en `src/features` y el acceso a datos en `src/services`.
- Identifica los datos y los flujos de demostración como tales. Usa oportunidades aprobadas para las recomendaciones.
- Conserva los tokens Rosewood y las familias Playfair Display y DM Sans.
- Solicita autorización de la fundadora antes de crear recursos externos o desplegar públicamente.
