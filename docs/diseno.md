# Sistema de diseño

Rosewood Editorial Minimalism combina marfil cálido, tipografía serif editorial y una fotografía de colaboración universitaria. La portada utiliza una composición asimétrica. El explorador y Mi Nexo IA comparten los mismos controles, tonos y espaciados.

| Token | Valor | Uso |
| --- | --- | --- |
| Primario | `#814D5A` | Acciones, cursivas y foco |
| Acento | `#C99BA5` | Detalles y contornos activos |
| Secundario | `#F2DDE1` | Superficies y acentos cálidos |
| Fondo | `#FBF8F5` | Lienzo principal |
| Texto | `#30272A` | Titulares y texto principal |
| Texto secundario | `#65565C` | Descripciones y metadatos |
| Borde | `#E3D7D9` | Divisores y tarjetas |
| Tarjeta | `#FFFFFF` | Superficies de interacción |

**Tipografía.** Playfair Display para titulares y DM Sans para lectura, navegación y formularios. Se distribuyen localmente mediante Fontsource y su licencia SIL Open Font License.

**Imágenes.** `public/estudiantes.webp` se generó para AyniNexo con OpenAI Image Generation y se optimizó a WebP. Representa una escena ilustrativa de colaboración universitaria. Las personas son ficticias y la foto no documenta a estudiantes de la UNI. El símbolo y el favicon son una creación original en `public/ayni.svg`.

**Interacción.** Los controles incluyen foco visible. El menú móvil admite Escape, los filtros tienen etiquetas y los estados funcionales combinan texto con color. El estilo respeta la preferencia de movimiento reducido.
