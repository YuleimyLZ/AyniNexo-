# Roadmap de AyniNexo

| Fase | Entregable |
| --- | --- |
| 1 | Frontend Rosewood, escenarios de ejemplo y primera revisión visual |
| 2 | Código de Auth y persistencia, migración, moderación y verificación en entorno de prueba. La validación en el proyecto de la fundadora requiere aplicar la guía |
| 3 | Edge Functions para extracción, recomendaciones explicadas y rutas generativas con Gemini |
| 4 | Revisión de convocatorias reales, verificación integral de roles y pruebas con estudiantes |
| 5 | Despliegue en Vercel y prueba de la Public Beta v0.1 con autorización |

La Fase 3 conservará el análisis determinístico de los requisitos. Las Edge Functions aceptarán los datos académicos mínimos, recuperarán las oportunidades aprobadas del backend y validarán las respuestas del proveedor. La extracción propondrá campos para revisión, y la publicación seguirá pasando por la operación de moderación. Configura la clave de Gemini solo como secreto de Edge Functions cuando la integración esté autorizada.
